自动截图设置

监控网络请求并在满足断言规则时自动捕获页面图像

等待页面 UI 渲染或提示出现后再进行截图

可用上下文变量：

  • status - HTTP 状态码（如 200, 404, 500）
  • statusText - 响应状态文本
  • method - 请求方法（GET, POST 等）
  • url - 完整的请求 URL
  • body - 响应体 JSON 对象
  • bodyText - 响应体原始文本
  • resourceType - 资源类型（xhr, fetch 等）

示例断言公式：

  • status >= 400
  • body && body.code !== 0
  • status >= 400 || (body && body.code !== 0)
